# Manrope

Source: https://github.com/google/fonts/tree/main/ofl/manrope
License: SIL Open Font License 1.1; see OFL.txt.

Regular (400), Medium (500), SemiBold (600), and Bold (700) are static instances of
Manrope[wght].ttf, generated with fontTools varLib.instancer. Family/style name records
identify the static weights so the font cache can select them consistently.
